# Réseau de diffusion simulé + analyse Neo4j

## Description

Ce projet simule un **réseau de diffusion de drogue fictif** à l’aide d’un graphe (NetworkX) et le visualise avec Matplotlib.  
Les données sont ensuite stockées et analysées dans une base de données **Neo4j**.

Le réseau contient différents types de profils :

- ☺ Normal  
- ● Consommateur  
- ⚠ Addict  
- ♠ Dealer  

---

# 🚀 Fonctionnalités

- 🎲 Génération aléatoire d’un graphe réaliste  
- 🎨 Visualisation interactive du réseau  
- 🔗 Création automatique des relations  
- 🗄️ Export direct vers Neo4j (sans CSV)  
- 📊 Analyse du graphe (nombre de nœuds, relations, etc.)  
- ⚡ Requêtes Cypher pour exploration  

---

# 🛠️ Technologies utilisées

- Python 🐍  
- NetworkX  
- Matplotlib  
- Neo4j  
- Neo4j Python Driver
